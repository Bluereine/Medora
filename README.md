Medora – Care. Always.

An elderly-care and medication management application designed to make everyday care more organised, accessible, and connected.

1. Chosen Challenge Vertical

Elderly Care and Healthcare Management

Medora focuses on supporting elderly individuals who may find it difficult to manage their daily medication schedules and healthcare routines independently.

It also addresses the challenge faced by family members and caretakers who want to stay involved in an elderly person's care.

2. Problem Statement

Managing multiple medicines, remembering dosage schedules, and maintaining daily healthcare routines can be challenging for elderly individuals.

At the same time, family members and caretakers may find it difficult to coordinate care and stay informed when they are not physically present.

3. Our Approach and Solution

Medora provides a connected platform for elderly individuals, family members, and caretakers.

The application uses role-based access to provide different interfaces according to the user's role. Its goal is to simplify medication management and make elderly care more organised.

4. Key Features

Medication Management: Add, edit, and manage medication details.

Medication Reminders: Support for organising medication schedules.

Role-Based Dashboards: Separate interfaces for elderly users, family members, and caretakers.

Connected Care: Designed to help family members and caretakers remain involved.

Accessible Interface: A simple interface designed with ease of use in mind.

5. How the Solution Works

Users access the application and register or log in.

Users interact with the application through their respective role-based dashboards.

Medication information can be managed through the medication management interface.

The platform is designed to support coordination between elderly users, family members, and caretakers.

7. Assumptions

Users have access to a smartphone or computer and an internet connection.

Elderly users may need assistance from family members or caretakers while using the application.

Medication details and schedules are entered based on information provided by the user or their healthcare professional.

Medora is a care-management support tool and does not replace professional medical advice or prescribe medication.

8. Project Setup

To run the project locally:

git clone YOUR_GITHUB_REPOSITORY_URL
cd Medora
cd frontend
npm install

Create a .env file in the frontend directory and configure the required Firebase environment variables:

VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=

Start the development server:

npm run dev

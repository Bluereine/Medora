Medora – Care. Always.

Medora is an elderly-care and medication-management application designed to help older adults manage their medicines while keeping family members and caretakers connected to their care.

Problem Statement

Elderly people may struggle to remember medication schedules and manage their daily medicines independently. Family members and caretakers may also find it difficult to stay informed about medication-related activities.

Our Solution

Medora provides a centralized platform with role-based dashboards for elderly users, family members, and caretakers. It aims to simplify medication management and improve coordination between elderly individuals and their caregivers.

Key Features

Role-Based Dashboards: Separate interfaces for elderly users, family members, and caretakers.

Medication Management: Add and manage medication information and schedules.

Medication Reminders: Display medication schedules to help users remember their medicines.

Family & Caretaker Access: Dedicated dashboards for people involved in an elderly person's care.

Accessible Interface: Simple and readable design focused on ease of use.

Installation & Setup

1. Clone the Repository

git clone https://github.com/Bluereine/Medora.git

2. Navigate to the Project

cd Medora

3. Install Dependencies

npm --prefix backend install
npm --prefix frontend install

4. Configure Firebase

Create a .env file inside the frontend directory and add the required Firebase configuration variables.

Do not upload your .env file or private credentials to GitHub.

5. Start the Frontend

cd frontend
npm run dev
